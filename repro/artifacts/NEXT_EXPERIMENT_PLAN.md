# 下一阶段实验计划：按风险分配输出长度，验证无信息损失的训练优化

状态：2026-11-04 V3 已完成。执行协议及源文件哈希保存在 `v3_contract.json`。
开发路由未达到 15% 费用下降门槛，因此未执行 160 题推理或评分；六次真实训练对照全部完成。
本阶段核算 12.9459 元，低于 30 元停止线；启动前含 30% 余量预测为 28.4203 元。
完整结果见 `V3_RESULTS.md`，整文件解析验证数据的实现偏差见其数据边界小节及 `v3_boundary_audit.json`。
后续优先整理复现报告、消融和负面结果，不在本轮开发数据上反复改规则追逐胜出。

## 研究问题与优先级

短输出在第二轮新测试中降低含缓存核算 42.1%，但准确率从 80.67% 降至 79.67%，
95% 配对区间 [−4.33, +2.00] pp，尚不能证明非劣。5 次格式失败回退没有补救出正确答案。
下一步优先研究是否能通过更保守的本地路由，在简单题上省输出、在复杂或不确定题上保留原始输出要求。

另行验证诊断调用剔除的真实执行费用。其零 API 回放已验证每步手册与选定手册相同，
但尚未测量新的真实训练费用；移除预热请求可能影响缓存，因此不能直接宣称实付节省 22.8%。

## 1. 开始前重新封存数据和协议

- 原训练 500 题已用于正式学习或 pilot 的为 70 题；尚余 430 题，不在本阶段临时扩充训练。
- 原验证 300 题已使用 100 题，尚余 200 题。按可复现 ID 顺序预先分成新开发 40 题、封存评估 160 题。
- 两批官方测试各 100 题都已开封，不再作为新方案的未见测试。
- 新的 160 题应称为“由未使用验证池重新划分的项目封存评估集”，不能称为新的官方测试集。
- 实验前记录 ID、原始数据哈希、模型与参数、手册、模板、路由规则、选择准则和预算。
  路由只依据问题文本和固定规则，不能读取正确答案或先看测试成绩再改分配。
- 同一模型、原始预处理和三份原始 ACE 冻结手册。继续保留温度、思考模式及 4096 输出硬上限。

## 2. 主实验：自适应输出，而非统一短输出

| 条件 | 经验输入 | 输出策略 | 模型调用 |
|---|---|---|---|
| A 原始 ACE | 原始完整手册 | 原始输出提示 | 每题一次 |
| B 固定短输出 | 同一完整手册 | 统一 60 词软约束 | 每题一次，无事后重答 |
| C 自适应输出 | 同一完整手册 | 仅通过开发验证的低风险题用短输出，其余用原始提示 | 每题一次 |

B 去掉事后重答是新的待验证条件；此前“去掉回退仍为 239/300”只是事后固定响应分析，不能当作本次独立结果。

路由规则保持简单且可解释：考察数值/运算复杂度、复利或期权等计算提示、百分比/金额换算风险、
题意信息是否不足，以及通用规则与具体规则可能冲突的信号。不能只信模型自报置信度。
默认走原始输出；只有新开发集支持的低风险范围才允许短输出。开发样本不足时不强行开启某条路由。
路由必须在模型生成前完成，不因答案错误而追加调用；完整手册始终保留。

开发阶段：40 题 × 3 份手册 × 2 种输出方式 = 240 条预测，用于固定一套路由，
并对问题级别的过拟合做交叉验证检查，不把三个手册输出当成三个独立问题。
没有满足开发准确率/效率门槛的路由，就停止，不打开 160 题评估集。

封存评估：三组 × 3 份手册 × 160 题 = 1440 条预测。主要比较提前指定为 C−A，B 作为消融。
三个手册之间轮换条件执行顺序；计入路由开销、全部 tokens、实际缓存和所有失败预留。
所有条件完成前不评分，不能按中途成绩替换规则或抽掉失败题。

## 3. 独立的执行优化检查：真实训练去诊断

先实施不伪造训练后准确率的正式训练入口：跳过的诊断标为未测量，保留全部反思、修正、整理与验证。
先跑 seed42 的一对真实训练，核查调用轨迹、日志完整性与预算；通过后做 seed43、44，形成三对。
每对都使用原 60 条训练和 30 条选模验证，训练顺序配对，基线与优化交替执行。

比较学习调用细分、输入/输出 tokens、缓存命中、含缓存费用核算、统一价格成本及墙钟时间。
新真实运行的模型响应不受顺序种子完全控制，不能要求两次在线生成的手册字节相同；
此前固定响应回放的等价证据与此次真实费用证据分开报告。

这组真实训练检查不使用新的 160 题，也不更换主路由实验的三份冻结手册，避免混合训练与推理两种变化。
选模验证成绩仅作开发观察，不作为新的独立准确率结论。

## 4. 指标、目标与停止条件

- 准确率是首要指标。目标为自适应方案点估计下降不超过 1 pp，同时含缓存推理核算下降至少 15%。
- 报告按题 ID 聚类的配对差值及 95% 区间、各手册结果和离散程度。
  若区间仍允许超过 2 pp 的下降，写为证据不足，不能宣称保证精度或正式非劣效。
- 同时报输出 tokens、有限数值输出率、截断率、路由到长/短模式的比例、API 及端到端中位数/P95。
- 学习优化单列训练与验证开销，不把历史归因当成实际缓存费用，也不把它与推理节省比例相加。
- 新阶段核算停止线建议 30 元，含失败与在途预留；全项目仍保留 180 元停止线。
  启动前按当前价格和已有 usage 再复算，预算不够则停止，不根据评估成绩缩样本。
- 无法核实的请求结果保留费用预留；鉴权、余额、指纹偏离或预算问题停止。
- 没有稳定收益则保留负面结果并转入报告整理，不反复更换规则追求同一评估集上的胜出。
