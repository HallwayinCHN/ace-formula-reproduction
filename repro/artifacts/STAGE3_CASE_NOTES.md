# 第三阶段案例解读：开封后探索性观察

以下案例来自冻结规则自动选出的组合方案相对 ACE 的改善/退化题目。
只解释已观察到的输出，不改标签、不重算主结果，也不据此调整本次方法。
ID 为原始测试 JSONL 的零起始行号；详细的十五组输出见 `stage3_cases.json`。

| ID | 现象 | 可以支持的解释 |
|---|---|---|
| 64，GDP | GDP 为 4,250 billion；标签为 4,250,000,000,000。ACE 三次均答对；组合组 seed43 输出 4250，另两次正确。选择性组 seed43 也输出 4250。 | 这是金额量级归一化问题。该次错误在未检索的选择性组也出现，不能归因于检索。 |
| 33，ROI | 原始公式的计算值为 (58,000−50,000)/50,000=0.16；标签 0.16。ACE 三次输出 16，组合组只有 seed42 输出 0.16。 | 比率与百分比表示不稳定；一次改善不能证明检索稳定解决了该问题。 |
| 121，ROE | 原始公式给出 1,500,000/5,000,000×100=30。ACE 为 2/3，组合组为 3/3；空手册三次均输出 0.30。 | 此例显示经验有助于匹配该题输出约定，但不同组/种子仍会混用比率与百分比。 |
| 84，失业率变化 | 题目只说明劳动力增加 50,000、失业人数不变，没有给初始人数，原标签为 0.0。组合组某次输出信息不足；ACE 与其他组也有 0 或负数等输出。 | 可判断方向但不能唯一确定数值变化；这是题目/标签有效性的疑点。主评分仍保留 0.0，未用模型分歧作为改标签依据。 |

原始预处理 `parse_context_and_question_formula` 抽取 `Question:` 后的文本，移除题目前的公式说明，
再添加统一的浮点数与量级换算要求。因此上表的“原始公式”来自原始数据记录，不代表生成器看到了公式。
这一行为沿用上游，所有方案相同；不能把补回公式说明当作本次已经验证的改进。

组合组相对 ACE 的平均准确率差为 −1.67 pp；按题聚类的 95% 区间为 [−3.67, +0.33] pp。
单项选择性反思下降 4.33 pp、单项检索下降 2.67 pp，组合没有超过原始 ACE 的准确率。
现有结果支持“存在成本与准确率权衡”，不支持“两个单项都提升准确率”或“组合已证明非劣”。

后续若研究归一化、信息不足识别或语义检索，需明确标为探索性新方法，并使用新的验证/测试安排，
不能继续以当前已开封的 100 题充当未见测试。
