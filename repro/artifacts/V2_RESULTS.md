# 第二轮研究结果：完整经验手册＋简短输出＋解析失败回退

**状态：20 题筛选、40 题开发确认和剩余 100 题独立测试全部完成。**

第一轮 100 个测试 ID 用于诊断，第二轮独立测试 ID 与其零重叠。以下准确率只在同一行比较，不能把第二轮数值直接与第一轮的 84% 相减来算提升。

## 实际改动

保留三份原始 ACE 完整手册、同一模型、原预处理及数值匹配；不使用选择性训练手册。提示要求计算检查不超过 60 词，这是软约束；保留 JSON 字段和 4096 输出硬上限。若最终答案不是有限数值，再用原始提示和完整手册调用一次。回退不读取正确答案，两个调用的费用和耗时均计入。

学习成本没有改变。本次收益来自答题阶段，不能沿用第一轮选择性反思的学习节省比例来宣传新方案。

完整手册长度与知识内容没有减少，故这里的主要节省不依赖丢弃经验。含缓存核算采用冻结峰时单价和保守换算系数，不是已核对的服务商账单。耗时是本次服务和网络下的观测量，没有进行严格延迟显著性检验。

## 准确率保证的边界

保留完整经验、限制冗长输出、使用无标签回退，旨在保护知识与输出完整性，但有效性仍由独立测试判断，不能承诺所有题目或新任务准确率不下降。未进行正式非劣效检验。
本次区间仍允许超过 2 pp 的下降，不能保证 2 pp 以内的精度损失。

开发中另一候选保留固定通用规则、补全公式条目引用、必要时用完整手册回退。它在筛选中的准确率与最终候选相同，但含缓存核算更高，按预先排序没有入选；不能把它也称作已通过独立测试。

## 研究依据

[ACE](https://arxiv.org/abs/2510.04618v3)强调保留详细经验；[LLMLingua-2](https://arxiv.org/abs/2403.12968)把忠实保留作为压缩目标。本轮没有复现或直接采用它们在其他数据上的压缩收益。
[缓存感知压缩研究](https://arxiv.org/abs/2607.15516)及[DeepSeek 官方缓存说明](https://api-docs.deepseek.com/guides/kv_cache/)提示需要同时看 token、缓存和费用。本轮优先完整手册和稳定前缀，而非继续加大逐题删减。
按[官方峰时价格](https://api-docs.deepseek.com/quick_start/pricing/)，每百万输出 tokens 为 1.2 美元、缓存输入为 0.006 美元，单 token 价格比为 200。这是本任务在高缓存命中时优先优化输出的动机，不代表输入始终有缓存或费用可仅按 token 总数比较。

## 回退机制的事后检查

新方案相对基线有 7 次从错变对、10 次从对变错，净少 3 个正确输出。最终非有限数值输出由 14 次降到 2 次，但解析成功不等于计算正确。
本轮 5 次回退没有补救出正确答案。离线保留首次响应时，仍为 239/300；因此本次没有证实回退组件提高准确率。这只是对固定响应的事后消融，不是删掉回退后重新做的独立测试，也不能直接据此宣布新方案达标。

## 进一步的保守执行优化

另行实现并通过三份真实归档回放验证的诊断调用移除原型，不改变保留请求、每步手册或选定手册。学习调用按历史轨迹减少 23.02%，统一无缓存学习成本归因减少 22.83%。没有新增付费重训，实际缓存费用需另行测量，移除预热请求也可能改变缓存命中。详见 `DIAGNOSTIC_FREE_RESULTS.md`。这项执行优化独立于本报告的短输出方案，不能把两者的节省百分比直接相加。
