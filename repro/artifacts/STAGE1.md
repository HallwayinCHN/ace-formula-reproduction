## 已确认并保留的上游行为

1. 官方 Formula 预处理会移除问题前面的公式说明，500 条训练及 300 条验证全部走此分支。
2. 初次答对的训练样本仍会调用 Reflector；这是后续选择性反思的原始对照。
3. 原始离线入口可以自动运行测试。本试跑明确传空测试集合，验证只使用 validation。
4. 原始训练返回值仅含最佳验证准确率，逐检查点结果写在 `train_results.json`。
   本地模拟中发现并修正了新 harness 对返回值的错误假设，现改为读取上游实际输出。
5. 原始评估可能排除异常请求。本阶段遇到严重请求错误直接停止，并核验所有验证分母。

上游算法、提示词、答案解析和判分文件未修改。新接口适配的变化包括：关闭思考模式、
120 秒超时、每个请求最多三次尝试、认证错误停止、token/费用日志、20 元试跑记账线和 180 元项目记账线。
费用按官方峰时单价及保守换算系数估算，真实试跑后还需结合 API usage/账单核对。
